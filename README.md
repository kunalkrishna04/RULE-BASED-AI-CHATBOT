
## 📌 Overview
The Rule-Based AI Chatbot is a Python-based chatbot that responds to user queries using predefined rules and keyword matching. It simulates a simple conversation without using machine learning, making it suitable for learning chatbot fundamentals.

## ✨ Features
- Interactive text-based conversation
- Keyword-based response system
- Easy to customize responses
- Beginner-friendly implementation
- Fast and lightweight

## 🛠️ Technologies Used
- Python 3
- Pydroid 3
- Git & GitHub

## ⚙️ How It Works
1. User enters a message.
2. The chatbot checks for matching keywords.
3. If a keyword is found, it returns the predefined response.
4. If no keyword matches, it displays a default response.


## 💬 Example
```
User: Hello
Bot: Hi! How can I help you?

User: What is Python?
Bot: Python is a popular programming language.
```
